# Traf़ora / Traf़ora Growth Platform — Design Brief

- Design read: independent creators and small businesses need a clear, trustworthy place to share tracked links and organize campaigns without fake traffic.
- Concept spine: **attention, made accountable**. A single cobalt signal travels through every page from link to campaign to measurable click.
- Delivery tier: cinema-inspired product site with a light interactive motion system; the account environment prevents generated media creation, so motion is implemented with reduced-motion-aware CSS and real UI states.
- Animation mode: animated-website — user selected animated. Scroll-scrub footage generation was attempted but blocked because the connected generation service requires a Basic plan or higher; use honest custom CSS motion rather than broken video placeholders.
- Brand: original Trafora identity, functionally inspired by marketing link platforms but no copied marks or assets.
- Locked palette: cool light `#F6F8FC`, ink `#172033`, cobalt `#3F5FC4` (single accent), mist `#EAF0FF`, muted steel `#64718B`, white `#FFFFFF`. Cobalt reads as a precise signal and the warm-free palette avoids common neon-tech tropes.
- Locked type: Satoshi + JetBrains Mono for numeric/URL details. Sans display keeps the product crisp and legible.
- Hero: asymmetric 52/48 split; left headline and CTA, right a live interface visualization showing a link signal passing through a tracked-click card. The UI preview is a real component, not a generated mockup.
- Journey shape: single-shot concept. The actual film could not be generated due account plan gating; replace the missing film with a reduced-motion-aware CSS motion system and a fully functional interface preview.
- Journey: (1) Signal: create a clean link; (2) Measure: real visits update click totals; (3) Organize: campaign destinations and budgets live together; (4) Improve: review authentic aggregate performance.
- World grammar: cool light environment, matte white panels, crisp cobalt paths, soft silver edges, controlled highlights and ample negative space.
- Mobile framing: hero stacks into one column, the signal illustration moves above the fold, dashboard tables become stacked rows, and all forms remain usable at 320px width.
- Delivery budget: no generated video files are shipped; no placeholder video URLs. CSS motion is limited to transforms/opacity and disabled under `prefers-reduced-motion`.
- Section plan: hero split; feature editorial rows; workflow timeline; dashboard preview; FAQ; final CTA/footer. Each uses a distinct layout family.
- Asset plan: bespoke inline Trafora monogram and SVG signal motif; no external stock imagery. A custom OG image and image generation are unavailable under the current generation plan, so social preview metadata will use the site's own generated SVG mark until a generated cover can be made available.
- CTA inventory: `Ücretsiz başla` (primary onboarding), `Paneli aç` (dashboard), `Özellikleri gör` (section navigation), `Bağlantıyı kopyala` (copy feedback), `Link oluştur` (create flow), `Kampanya oluştur` (campaign flow).
- Product rules: no bot traffic, no fake stats, no forced redirects, no hidden subscriptions. Click counts only increment on non-obvious automated traffic; user IP addresses are not stored.
- Scope note: this first release includes accounts, tracked short links, campaign creation and click analytics. It does not buy ad inventory, serve third-party ads, process payments, or guarantee traffic; those need separate integrations and compliance work.
